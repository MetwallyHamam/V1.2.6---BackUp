# Documentation

The documentation folder uses three lifecycle folders for development ideas and work records:

- `Backlog` contains future ideas and features that are not yet approved for implementation.
- `Planned` contains approved, scheduled, or in-progress ideas and features.
- `Completed` contains finished implementation plans, completion evidence, release notes, and hotfix records.

Move a document from `Backlog` to `Planned` when the decision is made to work on it. Move it from `Planned` to `Completed` after implementation and verification are finished.

Current operational guides, policies, runbooks, and system reference documents remain in the root of this folder because they are maintained documentation rather than lifecycle work items.

## Completed archive

- `Completed/Plans` contains completed plans, implementation status records, audits, and stop points.
- `Completed/Releases` contains release and hotfix notes.
