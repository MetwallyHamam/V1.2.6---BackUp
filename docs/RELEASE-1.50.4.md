# SupportHub 1.50.4

## Changes

- General Dashboard now defaults to the first day of the current local month through today instead of year-to-date.
- Top Management Dashboard uses the same shared month-to-date default and reset behavior.
- The Top 3 agents trophy leaderboard includes only Support department employees who handled at least one ticket in the selected period.
- The complete agent KPI report remains available across departments.

## Database

Required revision remains `0145_ticket_scale`; no new migration is added.
