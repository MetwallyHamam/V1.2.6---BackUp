# Knowledge Base

Knowledge articles support draft and published lifecycle states, immutable
version snapshots, categories/tags, internal versus client-portal visibility,
permission-controlled creation/publishing, and text search. Portal queries return
only published, explicitly client-visible articles.

Search tokenizes the query and matches every token across title, summary, body,
category, and tags. Employees can link applicable articles to visible tickets;
duplicate links are rejected and link/unlink actions are audited.

Rich-text HTML, review expiry, feedback, and SQL Server
full-text indexing remain subsequent enhancements.
