# Workforce Shifts

Implemented workforce foundations:

- Day, night, on-call, and leave shift types
- Employee/team schedule records
- Primary and backup on-call roles
- Timezone-aware start/end timestamps
- Overlap detection
- Privileged overlap override requiring a recorded reason
- Audit event for every created shift and override
- Handover-note persistence foundation
- Shift calendar administration screen

Recurring shifts, leave approval, shift swaps, visual month/week/day calendar,
and shift-aware automatic assignment remain subsequent enhancements.
